Sum up 19 November's world news in one image — entry.png is a front-page summary of the world's news of Thursday 19 November 2026.

## Run it

```
python3 main.py
```

## What's in this repo
- `entry.png` — 1024×1024 PNG (limit: 1 MiB, 1024×1024). Front page "THE WORLD TODAY — 19 November 2026" with 32 stories from 6 continents, a world-map panel and a professional newspaper look (winner-1 recipe).
- `main.py` — Python 3, copies `entry.png` to `/output/entry.png`. No network, deterministic (same bytes on every run).
- `build_image.py` — the script that generated `entry.png` from the verified headlines (for the transcript / reproducibility).
- `.makefun/owner.json` — Idoy's public Solana wallet address, proving repo ownership.
- `LICENSE` — MIT.
